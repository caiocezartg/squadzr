Mockup · Painel admin V1
Painel admin

Referência visual da spec. Mesmo design system do app (tokens, tipografia, cantos retos), em um layout próprio em /admin: sidebar de administração no lugar da sidebar de squads, conteúdo em tabelas densas no lugar dos cards. Os textos de interface ficam em português, como o resto do app.

AcessoSó quem tem papel admin. Para os demais, /admin responde 404. O link “Admin” aparece no menu da conta só para admins.
Ações destrutivasSempre em um diálogo de confirmação. Fechar um squad exige um motivo, que vai para a auditoria e para os membros; mudar um papel não pede motivo.
ResponsivoAbaixo de 1024px a sidebar vira drawer (mesmo padrão do app); abaixo de 640px as tabelas viram listas de linhas.

A lista de usuários (não desenhada aqui) é uma tabela com avatar, nome, ID do Discord, data de entrada, papel (Usuário Moderador Admin Dono, o dono em mint cheio) e squads abertos, com busca por nome ou ID do Discord. A ficha soma o que o admin precisa para suporte: limites atuais (2/3 squads, 1/1 hospedando), squads abertos agora e histórico.

Papéis: o dono muda o papel de qualquer outra pessoa entre Usuário, Moderador e Admin; um admin muda só o de usuários e moderadores; ninguém muda o próprio papel nem o do dono. O seletor fica travado com o motivo embaixo (“Você não pode mudar o seu próprio papel.”, “O papel do dono não pode ser alterado.”, “Só o dono pode mudar o papel de um admin.”). Um moderador vê a ficha sem o seletor, e o menu dele mostra só Visão geral, Squads e Usuários.
